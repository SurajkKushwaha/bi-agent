⑤ Describe the data for the agent

Code can see tables and columns. Only a person knows what they mean. That knowledge goes into one file.

data_notes.md
Tables
orders · order_items · customers · targets · promos · reviews …
Column values
order_status = delivered | shipped | canceled
targets.month = '2018-06'
How tables join
customers.customer_state = region_map.state
Business definitions
revenue = SUM(price) of delivered orders
"last month" = August 2018
Known data problems
September 2018 is incomplete
50 orders have two reviews
Without itthe agent sees columns but guesses what "revenue" means.
With itevery answer uses the same definitions and warns about known problems.
Where it goesinto the agent's system prompt, so it applies to every question.
